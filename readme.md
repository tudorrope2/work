# 💬 학과 익명 Q&A 게시판

## 1. 서비스 소개
* **대상 사용자:** 특강이나 시험 직전 등 질문이 많은 학과 학생들
* **핵심 기능:** 
  * 익명으로 자유로운 질문 작성 및 **카테고리(시험, 과제, 기타) 선택 기능**
  * 실시간 질문 목록 확인 및 **키워드 검색 기능**
  * 유용한 질문에 대한 공감(추천) 및 댓글 기능
* 시험 전날 밤 등 갑작스러운 트래픽이 몰리는 상황을 가정한 학과 맞춤형 Q&A 웹 서비스입니다.

## 2. AWS 구성도 및 서비스 선택 이유
* **요청 경로:** 브라우저 (사용자) -> AWS EC2 (8080포트) -> Nginx 컨테이너 (80포트) -> Python Flask 컨테이너 (5000포트)
* **AWS 서비스 (EC2):** 기존 로컬 환경에서 검증된 Docker Compose 앱을 가상 서버 환경에서 가장 직관적으로 구동하고 포트(보안 그룹)를 관리하기 위해 EC2를 선택했습니다.
* **ELB 및 Auto Scaling 검토 근거:** 시험 직전 등 특정 시간에 트래픽이 집중되는 서비스 특성상, 연결 분산을 위한 ELB(ALB)와 부하 지표에 따른 서버 증설을 위한 EC2 Auto Scaling의 도입을 검토했습니다. 그러나 현재 예상되는 학과 단위의 트래픽 규모로는 단일 EC2 인스턴스로도 응답 처리가 충분하다고 판단하여 실제 구축은 생략하고 비용 효율성을 우선시했습니다.

## 3. 실행·배포·준비 사항
* **배포 서버:** AWS EC2 (Ubuntu)
* **포트 정보:** 호스트 8080 -> Nginx 80
* **실행 명령:** 
  1. `git clone https://github.com/tudorrope2/work.git`
  2. `cd work`
  3. `sudo docker compose up -d --build`
* **접속 주소:** `http://3.25.228.168:8080/`

## 4. 검증 및 기능 시험 결과
| 기능명 | 정상 케이스 입력 및 기대 결과 | 실패/경계 케이스 입력 및 기대 결과 | 실제 결과 |
|---|---|---|---|
| **1. 질문 등록 및 카테고리** | 카테고리 선택 후 내용 입력 -> 뱃지와 함께 최상단에 즉시 표시 | 내용을 비워두고 등록 클릭 -> "내용을 입력하세요" 경고창 발생 | 정상 작동 |
| **2. 질문 목록 조회 및 검색** | 검색창에 키워드 입력 후 검색 -> 해당 단어가 포함된 질문만 필터링 | 일치하는 검색어가 없을 때 -> "등록된 질문이 없습니다" 안내 문구 표시 | 정상 작동 |
| **3. 공감 누르기** | 공감 버튼 클릭 -> 해당 질문의 공감 수 1 증가 | 빠르게 연속 클릭(광클) -> 버튼이 비활성화되며 중복 증가 방지 | 정상 작동 |
| **4. 댓글 달기** | 댓글 텍스트 입력 후 등록 -> 해당 질문 하단에 릴레이로 표시 | 빈칸으로 댓글 등록 클릭 -> "댓글을 입력하세요" 경고창 발생 | 정상 작동 |

## 5. 기록
* **AI 활용 기록:** 프로젝트 기획 및 기본 HTML/Python Flask 코드 구조 작성, 검색/카테고리 기능 고도화 시 일반 AI(Gemini)의 도움을 받았으며, Cursor, Claude Code 등의 에이전틱 코딩 도구는 사용하지 않았습니다.
