# ⚡ 실시간 멀티 타이핑 아레나 (Real-time Multi-Typing Arena)

Python(Flask)과 Socket.IO를 활용하여 여러 사용자가 같은 방에 접속해 실시간으로 한글 문장 타이핑 속도와 정확도를 겨루는 웹 애플리케이션입니다. Docker Compose를 통해 AWS EC2 환경에 컨테이너 형태로 배포되어 있습니다.

---

## 🛠️ 기술 스택 (Tech Stack)
* **Backend:** Python 3.9, Flask, Flask-SocketIO
* **Frontend:** HTML5, CSS3 (Light Theme UI), Vanilla JavaScript, Socket.IO Client
* **Infrastructure & DevOps:** Docker, Docker Compose, AWS EC2 (Ubuntu), Git / GitHub

---

## ✨ 주요 구현 기능

### 1. 실시간 방(Room) 기반 멀티플레이
* 닉네임과 방 코드를 입력하여 독립된 게임 방에 입장할 수 있습니다.
* 방에 접속 중인 참가자 목록이 실시간으로 동기화되며, 우측 상단의 **`🚪 메인으로 나가기`** 버튼을 통해 언제든 로비로 복귀할 수 있습니다. (퇴장 시 참가자 목록 및 진척도에서 즉시 제외)

### 2. 실시간 타자 측정 및 글자 하이라이팅
* **실시간 타수(CPM) 및 정확도(%) 계산:** 타이핑 시작 시점부터 경과 시간을 분 단위로 환산해 실시간 타수와 정확도를 상단에 표시합니다.
* **직관적인 글자 피드백:** 
  * 맞춘 글자: 초록색 배경 하이라이트
  * 오타 발생: 빨간색 배경 경고 표시 (오타 수정 전까지 진척도 증가 중단)
  * 현재 입력 위치: 하늘색 밑줄 커서 표시

### 3. 실시간 진척도 공유 및 중복 시작 방지
* 각 참가자의 정확한 입력 비율(`%`)이 모든 참여자 화면의 프로그레스 바(Progress Bar)에 실시간으로 반영됩니다.
* 게임이 시작되면 모든 참가자 화면에서 `게임 시작` 버튼이 자동으로 숨겨져, 플레이 도중 타인에 의해 게임이 초기화되는 현상을 방지합니다.

### 4. 게임 종료 결과 모달(Modal) 및 재시작 흐름
* 한 참가자가 문장을 완주하면 본인과 상대방 화면 정중앙에 **완주 결과 팝업(타수 및 정확도)**이 실시간으로 표시됩니다.
* 팝업의 `확인` 버튼을 닫으면 하단에 **`🔄 게임 재시작`** 버튼이 활성화되어 다음 라운드를 바로 이어갈 수 있습니다.
